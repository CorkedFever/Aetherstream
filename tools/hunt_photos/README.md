# Hunt photos

Drop a picture of a hunt mark in here, named after the mark: `Laideronnette.png`,
`Sabotender Bailarina.jpg`, `Vogaal_Ja.png`. Case, spaces and underscores do not matter.
Any screenshot will do; the show treats it as a trail-cam photograph, terrain and all.

Then run, from the repository root:

```
python tools/make_hunt_photos.py
```

and rebuild. The wildlife show uses the photo on the mark's WANTED poster, on the fact card
in the close-up, and in Mogwyn's field notes. In the field the mark stays a shape in the
grass; nobody has seen one up close.

Gamer Escape's monster pages carry a "Hunt:" image for every mark, which is what these were
made for. Its image host only talks to browsers, so save them by hand.

Images here are not committed; only the packed `data/hunts.json.gz` is.
